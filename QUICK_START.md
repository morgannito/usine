# 🚀 Démarrage rapide - Usine Factory Game

## Méthode 1 : Docker (Recommandé) 🐳

```bash
./start-docker.sh
```

Puis ouvrez http://localhost:8080 dans votre navigateur !

## Méthode 2 : Sans Docker 📁

```bash
# Avec Python
python3 -m http.server 8000

# Ou simplement ouvrir index.html dans votre navigateur
open index.html
```

## Contrôles de base 🎮

- **WASD / Flèches** : Déplacer la caméra
- **Molette** : Zoom
- **Clic gauche** : Placer un bâtiment
- **Clic droit** : Inspecter un bâtiment
- **Espace** : Pause/Play

## Premiers pas 🎓

1. **Trouvez un nœud de ressource** (cercle coloré sur la carte)
2. **Placez un extracteur** dessus
3. **Placez un fourneau à côté** de l'extracteur
4. **Les ressources circulent automatiquement** entre bâtiments adjacents !
5. **Continuez la chaîne** en plaçant des assembleurs

## Astuces 💡

- Les **lignes dorées** montrent les flux de ressources
- Un **point vert** = bâtiment en production
- **Clic droit** sur un bâtiment pour voir son inventaire
- Alignez vos bâtiments pour créer des chaînes automatiques !
